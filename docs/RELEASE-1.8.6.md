# PicLite 图轻 v1.8.6

- 修复桌面端工作台“导出位置”未显示及固定文件夹设置不生效的问题，并将工作台与悬浮窗的文件设置明确分组、独立保存。
- 文件夹监测新增“保存到原图所在文件夹”，新建任务会递归处理目录中已有图片；同时修复子目录事件导致遗漏或重复处理的问题。
- 悬浮窗压缩规则新增目标文件大小，可在普通静态图片上自动调整画质与尺寸以尽量满足上限。
- 批量重命名新增“保留原图”选项，并支持在一次任务中同时重命名和转换 JPEG、WebP、PNG；文件夹监测也可组合格式转换与父目录命名规则。
- 增加文件夹初始扫描、目标体积约束、批量转换回滚和工作台/悬浮窗设置隔离的回归测试。
