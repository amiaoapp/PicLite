# PicLite 图轻 v1.8.2

- 恢复三档“超级压缩”策略：无损优先、智能平衡和更小体积会实测原格式、WebP、JPEG 与 PNG，并选择体积收益最好的有效结果。
- 无损优先改为肉眼高质量压缩，避免大量图片始终显示 0%；智能平衡保持原尺寸，更小体积同时降低画质和尺寸。
- 修复 Windows 与 macOS 悬浮窗无法稳定接收剪贴板图片的问题，并恢复首次启动时的剪贴板监测默认设置。
- 修复非覆盖导出丢失智能择优格式，以及覆盖原文件时扩展名可能与实际编码格式不一致的问题。
- 修复图片导入完成后仍显示“正在导入”的状态残留，并优化 PNG 调色板编码速度。
- 补充静态图片、透明图片、动态 WebP、水印、剪贴板与文件夹监测回归测试。
