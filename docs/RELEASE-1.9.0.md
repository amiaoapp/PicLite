# PicLite 图轻 v1.9.0

- 悬浮窗默认显示位置可选择屏幕四角，修复位置设置未实际生效的问题；新增鼠标穿透开关，可在设置中关闭以恢复悬浮窗操作。
- GIF 与动态 WebP 智能压缩默认以 500 KB 为目标，手动指定的体积上限优先生效。根据实际输出大小逐级降低画质、等比例缩小和抽帧，保留播放总时长与循环设置。
- GIF 使用有序点阵抖动减轻减色后的色带，并保留局部帧压缩优势；动态 WebP 使用完整颜色编码，保持平滑效果。
- 修复动图忽略目标体积上限、缩小后界面仍显示旧尺寸的问题；GIF 编码避免反复展开全部完整帧，减少等待时间和内存占用。
- 实测 9.70 MB、23.8 秒录屏 GIF：智能择优输出约 463 KB、512 × 274 的动态 WebP；指定 GIF 输出约 449 KB、256 × 137。输出均保持动画时长与无限循环。
- 补充动图体积约束、抽帧时序、透明度、循环次数、点阵减色及格式编码回归测试。
