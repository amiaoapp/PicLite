## PicLite 图轻 v2.2.2

- 精简工作台的压缩参数面板。快速方案并排，格式、画质、目标体积和尺寸直接可调；批量像素上限、水印和元数据可在「高级选项」中展开。
- 实时试压体积固定显示在右侧底部一行，实际像素尺寸和目标体积状态显示在中间结果区。「按此参数应用到全部」固定在底部，并显示图片数量。
- APNG 支持等比缩放和目标体积，保留全部动画帧及播放参数。无法达到目标时，结果会明确标注。
- 工作台会跳过已在队列中的相同图片。桌面悬浮窗仅在桌面版提供，网页和 Docker 版不再显示悬浮窗入口。

桌面、网页和 Docker 共享工作台更新；APNG 缩放及目标体积也可通过 MCP 调用。
