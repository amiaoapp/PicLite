## PicLite 图轻 v2.1.0

### 桌面悬浮窗

- 新版悬浮窗采用两排三列的大按钮，按窗口尺寸自适应，恢复直接可用的完整底部菜单。
- 隐藏悬浮窗文件名，保留导出文件名及图片元数据；悬停时显示操作按钮与磨砂背景。
- 经典悬浮窗恢复 v2.0.2 的圆形按钮、渐变信息区、底栏和右上收起按钮，支持与新版随时切换。
- 修复多张结果页码始终显示 `1/3` 的问题；切换结果不再改变历史列表顺序。
- 修复收起还原及样式切换后操作控件可能残留的焦点状态。
- 保留压缩预设和处理结果，未修改本次悬浮窗修复涉及的压缩核心与默认参数。

### 工作台与自托管

- 更新图片工作台和对比界面，优化放大字号时的布局。
- 提供独立裁切编辑窗口，完善悬浮预览尺寸适配。
- 完善浏览器工具页面及插件导入设置布局。
- Docker 多架构镜像改用原生构建，并执行容器运行检查。

### 下载

- Windows x64 / ARM64：安装程序（EXE / MSI）和便携 ZIP；需要 WebView2 Runtime。
- macOS Apple Silicon / Intel：DMG。
- Linux x64 / ARM64：AppImage / DEB。
- `SHA256SUMS` 提供下载文件校验值。

Windows 发布检查包含 x64、ARM64 原生构建、Rust 回归、MCP 集成测试，以及打包后应用的实际 WebView2 悬浮窗自动化测试。自动化覆盖真实本地压缩、20 种窗口布局、底栏点击、收起还原、分页、历史顺序与预设保留；不等同于所有 Windows 版本及显示配置的人工验收。
