## PicLite 图轻 v2.1.5

- 修复悬浮窗复制后粘贴回工作台时被转换为 PNG、体积变大及文件名丢失的问题；保留压缩结果的原始编码数据、格式与文件名。
- macOS 复制同时提供原格式图片与浏览器可读取的图片文件表示，改善网站编辑器粘贴兼容性。Qimiao 用户请同步更新至 1.1.7。
- 修复悬浮窗压缩已完成、但预览尚未加载时仍持续显示转圈的问题；缺失结果或失败时明确显示错误。
- 移除悬浮窗设置中已失效的“紧凑 / 完整”布局选项，保留堆叠、展开和窗口尺寸调整。
- 压缩算法、质量参数、格式选优、尺寸与目标体积策略保持不变。

Windows x64 / ARM64：EXE、MSI、便携 ZIP；macOS Apple Silicon / Intel：DMG；Linux x64 / ARM64：AppImage、DEB。网页、Docker 与 MCP 使用同一发布源码；Docker 同步构建 amd64 / arm64 镜像。
