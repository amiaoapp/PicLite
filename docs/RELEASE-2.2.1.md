## PicLite 图轻 v2.2.1

- 悬浮窗默认复制压缩文件，保留结果的格式、文件名和字节。对于不支持直接粘贴 WebP 图片的应用，请使用「兼容复制」。旧默认按钮布局自动更新，自定义布局保留。
- 修复桌面端静态 WebP 转 PNG / JPEG 时可能输出 WebP 的问题；支持将动态 WebP 转为 GIF，保留动画帧、播放时长和循环次数。
- 支持 APNG 无损压缩，保留透明度、动画帧和播放参数。
- 悬浮窗已有压缩结果时，底部「＋」仍可继续添加本地图片。

动态 WebP 转 GIF 和 APNG 无损压缩同步支持桌面、网页和 Docker；MCP 也可调用这两项功能。
