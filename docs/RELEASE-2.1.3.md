## PicLite 图轻 v2.1.3

- 修复使用 Cmd+Tab、Alt+Tab 等键盘方式切换窗口后，悬浮窗卡在悬停按钮页，或鼠标重新移入后不显示按钮、必须点击才能恢复的问题。悬浮窗现在按系统鼠标位置同步显示，失去焦点时仍能响应移入、移出。
- 同步处理切换窗口后残留的键盘焦点，避免操作遮罩一直显示；保留键盘操作、自动隐藏和鼠标穿透行为。
- 堆叠和展开列表共用本次修复，展开时每张图片独立响应悬停，滚动后自动更新当前图片的操作按钮。

Windows x64 / ARM64 提供 EXE、MSI 和便携 ZIP；macOS Apple Silicon / Intel 提供 DMG；Linux x64 / ARM64 提供 AppImage、DEB。下载后可用 SHA256SUMS 核对完整性。
