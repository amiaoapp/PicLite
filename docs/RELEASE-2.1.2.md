## PicLite 图轻 v2.1.2

- 修复工作室布局中插件页无法滚动、内容和底部按钮显示不全的问题。统一插件的可滚动区域，并修正紧凑模式的标题栏高度计算；经典布局同步兼容。
- 重新整理格式转换界面：源图片、转换设置与结果分区更清楚，常用输出格式改为带用途说明的快捷卡片，保留全部格式、质量和保存位置设置。桌面版、网页版及 Docker 同步更新，兼容深色外观和窄屏。
- 改善 macOS 悬浮窗四角的毛边：减少原生窗口、WebView 和网页层的重复圆角裁切，按屏幕倍率配置原生图层抗锯齿，使图片和悬停遮罩共用同一外轮廓。Windows 保留网页层的圆角边界。
- 修复悬浮窗没有图片时，菜单漂到窗口中间、底部出现多余空白的问题；恢复原有空白样式和底部单行菜单。
- 展开结果的图片铺满悬浮窗显示区域，按当前窗口比例逐张向下滚动，沿用堆叠时的圆角、压缩信息和悬停按钮；移除宽留白，修复旧固定高度引起的按钮重叠。
- 改善封面制作中图片和背景圆角的锯齿：提高预览渲染精度，导出时逐级缩小，保留透明边缘的平滑过渡；导出尺寸、预设和拖拽坐标保持正确。
- 收紧工作室图库页的标题区域，让图片列表获得更多显示空间。

Windows x64 / ARM64 提供 EXE、MSI 和便携 ZIP；macOS Apple Silicon / Intel 提供 DMG；Linux x64 / ARM64 提供 AppImage、DEB。下载后可用 SHA256SUMS 核对完整性。
