# PicLite 图轻 v2.0.1

- 新增可选的新版工作台，保留经典界面并默认使用经典界面。右上角可以切换布局，当前图片、参数和压缩结果保持不变。
- 修复经典界面配色被固定背景覆盖的问题。两套布局均支持四种配色和浅色、深色、跟随系统外观。
- 修复新版深色预览区过亮、标题栏右侧留白，以及窄窗口中“导出全部”被挤压截断的问题。
- 增加尊重系统减少动态效果设置的入场和图片交互动效，整理中英文 README 与桌面、网页、Docker 能力说明。
- 修复 WebP 编码失败直接终止进程的问题：不支持的尺寸返回错误，智能择优跳过失败候选并保留其它有效结果。新增超长图片回归和 MCP 进程恢复测试。

本次保留原有压缩、GIF、水印、导出和插件处理流程；原生处理改动仅限上述 WebP 稳定性修复。

验证包括本机原生与前端回归、类型检查、静态网页构建、macOS 界面与真实压缩实测，以及 Windows x64 / ARM64 等平台的 CI 原生回归、MCP stdio / HTTP 文件处理测试和安装包构建。Windows 桌面交互和整夜休眠恢复尚未完成真人实测，CI 通过不代表这些场景已得到验证。
