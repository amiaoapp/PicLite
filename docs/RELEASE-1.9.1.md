# PicLite 图轻 v1.9.1

- 支持苹果 HEIC／HEIF 照片输入，可在工作台、悬浮窗、格式转换插件和文件夹监控中导入、预览并压缩为 JPEG、WebP、PNG 等格式；不提供 HEIC 输出编码。
- 悬浮窗底栏加入鼠标穿透开关，空窗和结果窗都能随时切换；开启后穿透开关本身仍可点击。
- 新增折叠为 PicLite 小图标：图标可拖动，单击展开，保留原尺寸和处理结果，并在移动后的位置展开。有图时折叠按钮位于右上角，空窗时位于穿透按钮旁边；悬停显示并提供用途提示。
- 优化大图压缩速度：仍比较 JPEG、WebP、PNG，但已经确定无法胜出的 PNG 候选会提前停止编码，减少无损优先等档位的等待。最终输出与完整比较结果保持一致。
- 避免为读取输出尺寸重复完整解码，减少原生预览的额外处理。
- 补充大图候选结果一致性、PNG 候选提前停止和悬浮窗拖拽回归测试，各平台打包前统一检查。
