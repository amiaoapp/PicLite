## PicLite 图轻 v2.1.1

- 修复展开悬浮结果后，当前图片错误铺在整个窗口背景的问题；每张结果独立显示。
- 统一图片、遮罩与窗口的圆角裁切，默认圆角调整为 24 px；保留手动设置的圆角。
- 移除旧版经典悬浮窗及其切换设置，统一使用新版悬浮窗。
- 图片数量移至顶部中央；压缩大小居中显示，压缩比例移至上方，精简底部占用，改善小窗口显示。
- 修复 Windows 点击右上菜单后，鼠标离开仍停留在遮罩操作页的问题，同时保留键盘焦点提示。
- 修复手机网页设置页的异常排版；优化平板、大屏工作台与设置布局。Docker 使用相同修复。
- 新增悬浮窗“自动封面”按钮：按“封面制作”中自动保存的预设生成当前图片的封面，再按封面设置的格式和质量压缩。支持撤销，保留原图和压缩预设。

首次使用自动封面，请在主界面“封面制作”中配置一次；修改参数会自动保存，也支持导入现有 JSON 预设。悬浮窗悬停时，右下方图片图标即可直接生成封面；也可把“自动封面”配置到六个快捷操作之一。

Windows x64 / ARM64 提供 EXE、MSI 和便携 ZIP；macOS Apple Silicon / Intel 提供 DMG；Linux x64 / ARM64 提供 AppImage、DEB。下载后可用 SHA256SUMS 核对完整性。
