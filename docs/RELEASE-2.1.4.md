## PicLite 图轻 v2.1.4

- 修复 MCP 生成封面的圆角边缘锯齿：按亚像素覆盖生成半透明边缘，圆角边框、图片与阴影使用同一遮罩。
- 改进 MCP 缩放透明图标的采样，减少细节混叠和透明区域杂色渗入，保留输出尺寸与 PNG 透明通道。
- 修复悬浮窗展开结果后无法拖动；恢复图片区域拖动，保留列表滚动、按钮和质量面板操作。
- 鼠标穿透开启后仅穿透开关可以点击，其余按钮和底部菜单均穿透。
- 复制压缩结果保留原始编码图片数据；macOS 不再写入文件路径或强制转换为 PNG。剪贴板管理器需要支持原格式数据，Qimiao 同步提供对应修复。
- 修复悬浮结果设置预览、工作室界面底部空白和快速方案图标；快捷键分别保留 Control、Command 和 Windows 键。
- 网页、桌面封面导出与 MCP 增加实际像素回归检查，Docker 发布流程验证真实容器的封面输出。

Windows x64 / ARM64：EXE、MSI、便携 ZIP；macOS Apple Silicon / Intel：DMG；Linux x64 / ARM64：AppImage、DEB。Docker 同步构建 amd64 / arm64 镜像。使用 SHA256SUMS 核对完整性。
